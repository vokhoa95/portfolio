# Khoa Vo Portfolio

A dependency-free, responsive personal portfolio built with semantic HTML and CSS.

## Preview

Serve the `dist` directory with any local static web server, or open `dist/index.html` directly.

## Publish with GitHub Pages

Upload this repository to your GitHub account. In Settings → Pages, select GitHub Actions. The included workflow publishes the `dist` directory when you push to `main` or run the workflow manually. Public repositories can use GitHub Pages on GitHub Free.

The site uses relative asset paths, so it works at either a user-site root or a project subdirectory. No package install or build is required.

## Update

- Content: `dist/index.html`
- Styling and responsive layout: `dist/styles.css`
- Downloadable résumé: `dist/Khoa_Vo_Resume.pdf`

The `.openai/hosting.json` file is hosting metadata for the initial Sites deployment and is not required for GitHub Pages. Do not add credentials or private company code to this repository.
